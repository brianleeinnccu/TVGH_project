# 8 features 5-Fold：全資料重訓方程式彙整

來源：`predict_8features_5fold.py` 最新輸出（`eight_features_5fold/*/*_full_data_model_formulas.csv`）。

使用方式：缺值先補 `Impute_median` → z(x) = (x − Scaler_mean) / Scaler_scale → 代入方程式得 logit(p) → p = 1 / (1 + e^(−logit(p))) → p ≥ Final_Threshold 判為陽性。

MMSE 模型使用 `class_weight='balanced'`，MoCA 模型不加權（與原程式相同）。
